# Security policy

## Supported version

Only the current `main` branch is supported during pre-alpha development.

## Report privately

Do not open a public issue for:

- donor, biospecimen, or health information;
- credentials, tokens, or signing material;
- unpublished enabling biotechnology details;
- facility, containment, or hazardous-process vulnerabilities;
- partner feed composition, assay, pricing, or chain-of-custody data;
- patent-sensitive unpublished results.

Report through the private security contact designated by the repository owner. Include affected
version, reproduction information that is safe to share, impact, and suggested containment. Do not
include real donor data in a reproduction case.

## Data prohibition

This source repository must never store personally identifiable donor information or the key that
links coded specimens to people. Use synthetic fixtures for tests. Analytical data imported in the
future must pass privacy, partner-confidentiality, and export review before commit.
